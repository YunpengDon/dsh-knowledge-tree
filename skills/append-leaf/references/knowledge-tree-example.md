### [2026/8/27] Python 文件写入模式：'w' 与 'a' 的区别
在 Python 中，打开文件进行写入操作时，选择正确的模式至关重要。`'w'`（write）和 `'a'`（append）是两种常用的写入模式，它们决定了新内容如何与已有内容交互。

### 核心区别

#### 写入模式对比

| 特性 | `'w'`（写入模式） | `'a'`（追加模式） |
|------|-------------------|-------------------|
| **文件存在时** | 清空原有内容 | 保留原有内容 |
| **写入位置** | 从文件开头写入 | 在文件末尾追加 |
| **原有内容** | 被完全覆盖 | 被完整保留 |
